# Myra 4.1 — Watchlist, safety, playback and system integration

- Collapsible sidebar with a compact rail (⌃⌘S), remembered between launches.
  A Watchlist section, bookmark on every poster, and a Watchlist shelf on Home.
- One fixed-width indexing indicator in the header. Manual Refresh always runs,
  each source shows its health, and a failing source retries without blocking
  the others.
- Library data moves to a compact catalogue in the library database. Your
  existing data is backed up first and the old cache is kept until the new
  catalogue is verified. Metadata saves no longer rebuild the Home catalogue.
- Pinned filter bar (Genre, Language, Year, Quality, Source) shared by Home and
  See All. See All opens a grid with sort and size controls.
- Search torrents inside Myra (Transfers → Search) using Torznab indexers.
  Add Indexer takes any Torznab URL and key, with Jackett and Prowlarr presets.
- Player: Previous and Next episode for series, subtitle sync, Picture in
  Picture, and Skip Intro when a chapter is marked as an intro.
- Automatic downloads of new episodes of followed series inside an off-peak
  window. Off by default.
- Menu bar item, Dock badge for active downloads, optional notifications,
  Spotlight title search, and Shortcuts actions. All can be switched off in
  Settings → Advanced.
- Insights (⌘7), personal ratings and private notes per title.
- Daily library backups, Backup Now, storage view, and a first-run setup.
- Needs Attention and Collections pages, and a best-version picker.
- Corrected app icon size to match other Mac icons; three icon designs with
  Aperture as the default.
- Translucent window with Off, Subtle, Standard and Strong settings.
